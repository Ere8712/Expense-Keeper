# Diseño y Prototipado - Expense-Keeper
En esta carpeta se consolidan los artefactos lógicos y la interfaz del MVP correspondientes a la
entrega semanal.

## Prototipo Interactivo (Alternativa a Figma)
En lugar de un diseño estático en Figma, hemos desarrollado el prototipo directamente en
**código interactivo (HTML5 y Tailwind CSS)** para simular fielmente la experiencia de usuario
final, incluyendo cambios de pestaña y navegación modal.

* `[ Ejecutar Prototipo Interactivo](../../prototypes/Expense-Keeper.html)`
*(Nota: Puede clonar el repositorio y abrir este archivo localmente en
cualquier navegador web, o visualizarlo directamente en GitHub).*
