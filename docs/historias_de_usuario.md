# Historias de Usuario - Expense Keeper

## HU-01 Registro de Gastos

**Como usuario**

quiero registrar mis gastos indicando monto, categoría y fecha,

**para** mantener un control organizado de mis movimientos financieros.

### Criterios de aceptación

* El usuario puede registrar múltiples gastos.
* El monto es obligatorio y debe ser mayor a cero.
* La categoría es obligatoria.
* La fecha debe ser válida.
* El gasto queda almacenado correctamente.

### Subtareas

* Diseñar wireframe del formulario de gastos.
* Definir modelo de datos para gastos.
* Definir reglas de validación.
* Elaborar criterios de aceptación.
* Documentar flujo de registro.

## HU-02 Clasificación de Gastos

**Como usuario**

quiero clasificar mis gastos por categorías,

**para** identificar en qué utilizo mi dinero con mayor frecuencia.

### Criterios de aceptación

* El usuario puede seleccionar una categoría.
* Cada gasto pertenece a una categoría.
* Las categorías son fáciles de identificar.

### Subtareas

* Definir catálogo de categorías.
* Diseñar selector de categorías.
* Documentar reglas de clasificación.
* Definir criterios de aceptación.

## HU-03 Visualización del Historial Financiero

**Como usuario**

quiero consultar el historial de mis movimientos financieros,

**para** revisar y analizar mis gastos registrados.

### Criterios de aceptación

* El usuario puede visualizar una lista de movimientos.
* Cada movimiento muestra monto, categoría y fecha.
* Los registros aparecen ordenados cronológicamente.

### Subtareas

* Diseñar wireframe del historial.
* Investigar herramientas de visualización.
* Definir estructura de reportes.
* Elaborar criterios de aceptación.
* Documentar flujo de consulta.

## HU-04 Gestión de Métodos de Pago

**Como usuario**

quiero registrar métodos de pago,

**para** identificar cómo realizo mis gastos personales.

### Criterios de aceptación

* El usuario puede registrar métodos de pago.
* El sistema permite asociar un método a un gasto.
* Los métodos quedan almacenados correctamente.

### Subtareas

* Diseñar formulario de métodos de pago.
* Definir estructura de datos.
* Elaborar criterios de aceptación.
